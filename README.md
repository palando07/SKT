# Buzdolabı Dedektifi (SKT)

Market fişinin fotoğrafından ürünleri ve tahmini son kullanma tarihlerini (SKT) kaydeden, bozulmak üzere olanları uyaran ve eldeki malzemelerle tarif öneren uygulama.

- `web/index.html`: tek dosyalık web prototipi ([canlı demo](https://claude.ai/artifact/PUXY4uwc7jzesAn6rRHXPW)). Fiş okuma ve tarif önerisi Claude içinde açıldığında çalışır.
- `PLAN.md`: MVP kapsamı ve mobil sürüm planı.
